Stage BTS SIO janv. – avr. 2026 · Loudun

Coentrepreneurs

Plateforme privée de l'association Les CoEntrepreneurs : annuaire des adhérents, calendrier des rencontres et inscriptions, messagerie et notifications. Installable sur mobile et ordinateur, en production pour les membres.

  • Développement complet en autonomie, des besoins jusqu'à la mise en production
  • Migration de Firebase vers Supabase auto-hébergé (Docker sur VPS, Nginx)
  • Notifications push navigateur (Web Push VAPID) via Edge Functions Deno, emails avec Resend
  • Rôles admin / adhérent / invité, validation des comptes, suivi des présences en temps réel
  • Flutter
  • Dart
  • Supabase
  • PostgreSQL
  • Docker
  • Nginx
  • Deno
  • Sentry

En cours depuis sept. 2026

Utolys

Point d'entrée unique entre Utolys et ses clients : demande d'aide, prise de rendez-vous, inscription aux formations, actualités. Une seule base de code pour le web, Android et iOS, publiée d'abord en application web installable.

  • Aucune liaison extérieure : polices et moteur de rendu embarqués, rien n'est chargé chez Google
  • Règles d'accès de la base éprouvées par une soixantaine de scénarios d'attaque, rejoués sur PostgreSQL compilé en WebAssembly
  • Données hébergées dans l'Union européenne
